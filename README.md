# AI-Dermatologist
An AI-powered dermatology application that helps users identify common skin diseases through image uploads and provides features like doctor consultation,
appointment booking, live chat, and reviews. The system ensures a user-friendly experience with verified doctors, notifications, and AI assistance for 
patient queries.
# Features
Profiles: Doctors and Patients can create and manage their profiles.
Disease Detection: Users can upload an image of the affected area, and the system will identify the possible skin disease.
AI Assistant Chatbot: Users can get guidance and answers to their queries related to skin diseases through an AI-powered chatbot.
Listing Verified Dermatologists: The system shows verified dermatologists with details like contact, timings, and consultation fees for further consultation.
Booking Appointments: Patients can easily book appointments with registered dermatologists, and doctors can create and manage their profiles.
Live Chat with Doctor: Patients can communicate directly with doctors through live chat to discuss their concerns.
Notifications: Users receive updates about appointments, messages, and other important activities within the application.
Reviews and Ratings: Patients can view and give reviews and ratings to dermatologists upon successfull completion of appointment.
